# 专属领域知识分卷 (示例)

> 💡 本目录 (`data/memory/topics/`) 存放细分领域的专属知识库。
> 助手会根据用户提问里的关键词**按需加载**对应的分卷，不相关时不占用额度。

## 怎么配置

在实例目录下建一个 `topics.json`（可以从 `topics.example.json` 复制），写明每个专题的名字、文件和触发关键词：

```json
{ "topics": [ { "name": "健身训练分卷", "file": "fitness.md", "keywords": ["健身", "训练", "跑步"] } ] }
```

然后把对应的 `fitness.md` 放进本目录即可。英文关键词按整词匹配，中文关键词按包含匹配。
